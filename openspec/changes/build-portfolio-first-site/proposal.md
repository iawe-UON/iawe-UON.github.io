## Why

现有站点以 NexT 默认文章列表为首页，能够承载博客内容，但无法集中呈现个人简介、联系方式、简历以及文章、软件著作权和专利等专业成果。需要在保留 Hexo 现有发布、标签、归档和评论能力的前提下，将站点升级为作品集优先的个人门户，并以轻量、可维护的方式改善响应式体验与视觉一致性。

## What Changes

- 将根路径 `/` 建设为作品集首页，集中展示个人定位、核心能力、精选成果、最新文章和联系入口。
- 新增 `/about/`、`/resume/`、`/achievements/` 页面，分别承载个人简介与联系方式、结构化简历、分类成果展示。
- **BREAKING** 将原首页文章列表迁移至 `/blog/`；现有文章详情永久链接、标签归档、历史归档和部署方式保持不变。
- 新增集中式作品集数据模型，以示例占位数据驱动简介、联系、简历和成果页面，并在可选字段缺失时隐藏无效界面。
- 新增轻量成果筛选与详情抽屉：桌面端从右侧打开，移动端从底部打开；仅展示文字信息和可选外链，不提供证书或附件预览。
- 将文章标签作为博客分类入口，保留 Hexo 原生标签归档、分页和 Utterances 评论，不新增独立分类体系或前端文章索引。
- 新增浅色/深色主题切换、统一圆角组件、三色视觉约束、响应式防溢出规则和键盘可访问交互。
- 不引入 SPA、后端、数据库、CMS 或新的生产依赖，继续使用现有 Hexo/NexT 构建与部署命令。

## Capabilities

### New Capabilities

- `portfolio-pages`: 定义作品集首页、关于页、简历页、集中数据模型、路由和可选内容降级行为。
- `achievement-showcase`: 定义成果分类筛选、空状态、桌面/移动详情抽屉及其键盘交互。
- `blog-experience`: 定义 `/blog/` 文章列表、分页、标签跳转、文章永久链接兼容和评论行为。
- `site-theme-accessibility`: 定义浅色/深色主题、主题持久化、三色与圆角视觉约束、响应式防溢出和可访问性要求。

### Modified Capabilities

无。当前项目没有已有 OpenSpec 主规格；本次行为均作为新能力定义。

## Impact

- 站点配置：Hexo 首页生成路径、NexT 菜单、中文菜单名称、主题自定义文件接入。
- 内容与数据：新增作品集页面源文件及统一数据文件，现有 `source/_posts` 继续作为博客文章来源。
- 主题层：新增少量 Nunjucks 页面模板、共享组件样式和原生 JavaScript 交互；不引入新的运行时框架。
- 公共路由：新增 `/about/`、`/resume/`、`/achievements/`、`/blog/`，根路径语义由博客列表改为作品集首页。
- 兼容性：现有文章永久链接、`/tags/`、归档、Utterances 配置、`hexo generate`、`hexo server` 和 `hexo deploy` 保持兼容。
